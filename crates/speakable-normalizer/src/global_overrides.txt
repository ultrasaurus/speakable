# Matching (left-side) for a word-only key (no punctuation, e.g. mr, html)
# is always case-insensitive — key case there is cosmetic only.
# Substitution (right-side) is literal (case can affect TTS pronunciation)
#
# Trailing period matters, though:
#   - No punctuation in the key (mr, html) -> matched as a whole word,
#     independent of whatever punctuation follows it in the source text.
#     Don't add a period to these; it would change how the key matches
#     (see below) and break the common no-period case.
#   - A period (or other punctuation) in the key (no., vol., jan.) ->
#     matched as a literal substring, period included. Required whenever
#     the bare word without it is a real word or name you don't want to
#     catch by accident (vol, Jan the name) — the period scopes the
#     override to only the abbreviation usage.
#   - A punctuated key is matched case-sensitively if it contains any
#     uppercase letter, case-insensitively otherwise. Use this when even the
#     period doesn't disambiguate: "No." (the "Vol. 31, No. 7" citation
#     abbreviation) needs its capital N, since lowercase "no." is the
#     ordinary word "no" ending a sentence — same distinction the sentence
#     splitter's ABBREVS list already makes for the same word
#     (speakable-splitter).
